# tor-connect

Один исполняемый файл для Windows (цель: от Windows 7 / Server 2008 R2), внутри которого **в одном процессе**
работают свежий Tor, SOCKS5/HTTP-прокси, мосты и автообновление списка мостов.
Без дочерних процессов, без отдельных плагинов, без установщика.

> **Статус: ранняя разработка (этап 0 — проба).** Готового продукта пока нет. Сейчас проверяется,
> что свежий Tor вообще собирается как библиотека, встраивается в один процесс и запускается на Windows 7.

## Цели

- Один процесс, один `.exe`: Tor встроен как библиотека, транспорты (obfs4, webtunnel, Snowflake) — на Go в том же процессе.
- Совместимость со старыми Windows: Windows 7 SP1 и Server 2008 R2 (Vista — по возможности). Классическая CRT, без UCRT.
- Автообновление мостов: список собирается через GitHub Actions, подписывается и раздаётся с нескольких зеркал.
  Клиент проверяет подпись; запасной список зашит в программу.
- Команды в стиле `-geo-update`, `-geo-update 200` (обновить GeoIP, если файлам больше 200 дней), комбинируемые между собой.
- Безопасные значения по умолчанию: прокси слушает только `127.0.0.1`.

## Что нужно понимать

- Tor не даёт «короткой цепочки»: путь всегда из трёх узлов. Проект этого не меняет.
- Проект не обещает анонимность лучше, чем у Tor Browser. Это инструмент доступа, а не замена Tor Browser.
- Windows 7 и Server 2008 R2 не получают обновлений безопасности от Microsoft; использование — на ваш риск.
- **Не публикуйте свои мосты и `config.json`.** Чем больше людей знает мост, тем быстрее его блокируют.

## Структура

| Путь | Назначение |
|---|---|
| `scripts/versions.env` | закреплённые версии и хэши зависимостей |
| `scripts/build-win-deps.sh` | сборка zlib, libevent, OpenSSL и Tor (статически, mingw-w64) |
| `cmd/probe` | пробная программа: Tor внутри одного процесса |
| `.github/workflows/probe.yml` | сборка и проверка на GitHub Actions |
| `docs/PLAN.md` | план работ |

## Сборка

Всё собирается на GitHub Actions (workflow `probe-win7`, запускается вручную или при изменении кода).
Готовый файл — в артефактах запуска. Локальная сборка не требуется.

## Лицензия

Будет выбрана после проверки совместимости лицензий всех компонентов (Tor, OpenSSL, libevent, zlib и др.).
До этого момента права не передаются; список сторонних компонентов будет в `THIRD_PARTY.md`.
