# План работ

Одна универсальная сборка (Go 1.20, Windows 7 SP1+). Расширенная сборка для Windows 10+ с самыми свежими
библиотеками и Snowflake — после завершения основной работы.

## Сделано
- **M0.** Tor 0.4.9 внутри одного процесса (статическая сборка mingw-w64, msvcrt), работает на Windows 7 SP1 и 10.
- **M1a.** Единый файл настроек `tecon.cfg` / `tecon` (поиск рядом с программой приоритетнее рабочей папки, автосоздание),
  перечитывание на лету через управляющий порт Tor, `Upstream` (direct/SOCKS5/HTTP с паролем и перебором), ключ `-upstream`.
- Ресурсы exe: иконка, версия, манифест совместимости Windows 7–10.
- **M1b.** Onion-службы (`HiddenService*` с корректным применением группой на лету), DNSPort, пропуск занятых портов с повторной
  проверкой, относительные пути от папки конфига, проброс портов `MapPort` (TCP: tor/direct/upstream) и `MapPortUDP` (напрямую).

## Дальше (по порядку)
1. **Транспорты в том же процессе:** obfs4 и webtunnel (библиотека lyrebird 0.3.0, Go 1.20): `internal/pt`, `go.mod`/`go.sum`.
2. **Перебор мостов:** пул из нескольких `Bridge` в `tecon.cfg`, проверка (рукопожатие на Go), отдача Tor рабочих,
   переключение при сбое, повторные проверки.
3. **GeoIP:** файлы внутри программы, команда `-geo-update [дни]`, подписанное зеркало (ed25519).
4. **Входящий прокси:** `Inbound` с SOCKS5 и HTTP на одном порту, логин и пароль.
5. **Служба Windows** с автоперезапуском, команды `-service …`, `-test-bridges`; команды комбинируются слева направо.
6. **Подписанный автообновляемый список мостов** (сборщик на Actions, зеркала, запасной список внутри программы).
7. **Расширенная сборка для Windows 10+:** свежий Go и последние lyrebird и Snowflake.
8. Лицензия, `THIRD_PARTY.md`, подписанные релизы, регулярный автобэкап.

## Риски
- Tor не рассчитан на перезапуск внутри процесса: при сбое Tor завершается весь процесс (смягчается службой с автоперезапуском).
- Windows 7: свежие библиотеки могут использовать недоступные API; каждый шаг проверяется на реальной Win7.
- Go 1.20 снят с поддержки: зависимости Go-кода фиксируются на совместимых версиях; для Win10+ планируется отдельная сборка.
